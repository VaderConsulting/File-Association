# File Association

C# .NET 2.0 library (`BrendanGrant.Helpers.FileAssociation`) that creates, reads, and deletes Windows file-extension associations in the registry via `FileAssociationInfo`, `ProgramAssociationInfo`, and `AssociationManager`, plus shell-change notify. The WinForms example (`FileAssociationExample`) lists extensions, ProgIDs, verbs, Open With, perceived types, and edit flags. Open `File Association.sln`.
